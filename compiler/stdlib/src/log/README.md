# @std/log

Severity-filtered log lines on stderr, with a threshold selected by RNX_LOG.

```rnx
info!("starting");
debug!("cache size: {}", 12);
warn!("retrying: {}", 2);
error!("failed: {}", "timeout");
println!("still on stdout");
```

Read the [overview](/docs/@std/log/overview) or open the [API reference](/docs/@std/log/api).
