# @std/math

Scalar math helpers on Math and the Vec2 value type for 2D geometry.

```rnx
import { Math, Vec2 } from "@std/math";

let v = new Vec2(3.0, 4.0);
println!(v.length());
println!(Math.sin(Math.PI() / 2.0));
```

Read the [overview](/docs/@std/math/overview) or open the [API reference](/docs/@std/math/api).
