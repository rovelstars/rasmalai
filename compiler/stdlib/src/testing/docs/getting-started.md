# Getting started with @std/testing

No install step: the module ships inside the compiler. Import what you need:

```rnx
import { blackBox } from "@std/testing";
```

## Copy this

Paste it into a file or run it straight in the playground:

```rnx
import { blackBox } from "@std/testing";

let x = blackBox(40 + 2);
print(x);
```
